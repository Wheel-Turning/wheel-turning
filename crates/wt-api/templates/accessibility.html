Accessibility

Wheel Turning aims to conform to WCAG 3.0, the draft accessibility guidelines from the W3C. Because WCAG 3.0 is still a draft, we also meet WCAG 2.2 level AA wherever the draft is undecided.

Standard and date

Evaluated against the WCAG 3.0 Working Draft of {{ draft }}. Last evaluated on {{ last_evaluated }}.

The tests we plan for every release use a keyboard alone, NVDA with Firefox, VoiceOver on iOS and macOS, TalkBack with Chrome, 200 percent text, 400 percent zoom, forced colors and reduced motion. Those tests have not been run yet. Until they are, the requirements that depend on them are listed as partly met or not met.
